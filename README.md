# 🇮🇳 Bharat Darpan

> A one-stop digital platform to preserve and showcase the rich culture and heritage of India, covering all 28 states and 8 union territories.

**🌐 Live Site:**(https://bharatdarpan.onrender.com)

---

## 📖 About

**Bharat Darpan** (formerly *Bharat Heritage Explorer*) is a web platform built to digitalize and preserve India's cultural heritage for future generations. It brings together information about the traditions, celebrations, landmarks, and flavours of every state and union territory in one place.

India's culture is vast and diverse, and much of it is scattered or at risk of being forgotten. Bharat Darpan aims to be a single, accessible window into that heritage.

## ✨ Features

- 🗺️ **All 36 States & Union Territories**: dedicated cultural information for each region
- 🎉 **Festivals & Traditions**: celebrations, customs, and rituals across India
- 🏛️ **Historical Places & Monuments**: iconic landmarks and heritage sites
- 🍛 **Cuisines**: authentic regional food and culinary traditions
- 🎨 **Art Gallery**: traditional art forms and visual heritage
- 📱 **Responsive Design**: works across desktop and mobile

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or later)
- npm or yarn

### Installation

```bash
Clone the repository
git clone https://github.com/aparajitha0/Bharat-Darpan.git

Move into the project folder
cd Bharat-darpan

Install dependencies
npm install

Start the development server
npm start
```

The app will run at `http://localhost:3000` (or the port shown in your terminal).

### Build for Production

```bash
npm run build
```
